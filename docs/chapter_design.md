# 章节设计

## 第一章：镜面花园
- 核心法则：对称
- 谜题类型：镜像门、镜面反射机关
- 玩法目标：玩家学会通过观察和操作镜像关系修复局部世界

## 第二章：映射工坊
- 核心法则：映射、输入输出
- 谜题类型：开关与映射线路、连锁装置
- 玩法目标：理解映射关系并操作机关完成连锁逻辑

## 第三章：钟摆塔
- 核心法则：周期、节拍
- 谜题类型：钟摆同步、节拍触发机关
- 玩法目标：通过节拍掌握周期规律，触发环境变化

## 第四章：连线水道
- 核心法则：连通、路径重组
- 谜题类型：水道、光路、节点连通
- 玩法目标：修复断裂路径，使全局连通

## 第五章：无穷观测所
- 核心法则：极限、渐近
- 谜题类型：渐进平台、边界逼近机关
- 玩法目标：理解极限思想，完成复杂连续操作

## 第六章：投影回廊
- 核心法则：投影、2D/3D映射
- 谜题类型：投影调整、空间翻折
- 玩法目标：学会在影界调整结构，改变实界状态

## 第七章：黎曼的扭曲花园
- 核心法则：非欧几何、曲率
- 谜题类型：弯曲路径、异常空间操作
- 玩法目标：适应非欧几何空间，实现目标路径

## 终章：法则熔炉
- 核心法则：拓扑、世界法则重构
- 谜题类型：莫比乌斯翻折、全局连锁重排
- 玩法目标：通过最终操作让世界秩序恢复，推动剧情结束
