# 美术与配乐设计（Art & Audio Direction）

## 一、总体风格
- **美术风格**：唯美遗迹风与纯净几何光影结合
  - 黄金分割、斐波那契比例作为场景布局参考
  - 结构化、对称性与曲率变化用于机关与环境提示
  - 颜色体系区分实界（3D）与影界（2D）
- **光影**：通过光影投射强化空间关系和法则可视化
- **材质与粒子**：用于提示交互点、法则作用范围和玩家操作反馈

## 二、空间与场景设计原则
1. 每个法则对应特定的视觉隐喻
2. 章节点周边场景强化法则主题，如对称、投影、曲率、拓扑
3. 场景引导自然体现，避免繁琐 UI 面板
4. 高阶区域（隐藏关、挑战深渊）使用更夸张的光影、色彩和异形空间强化边界感

## 三、配乐与音效设计
### 1. 数学法则映射音效
- **数论/质数**：单音阶音符，简洁纯净
- **合数**：和弦与复合音效，增加复杂度感
- **周期**：钟摆、轮盘节拍音，带有物理反馈感
- **连通**：水流、光脉传递声，强调流动感
- **极限**：渐近式音效，逐渐靠近高频或低频收束
- **投影**：光柱撞击声、投影折射声
- **曲率与拓扑**：空间回响和频率相位变化，表现非欧几何与翻折效果

### 2. 叙事与情绪
- 欧拉回声音色：低沉且略带机械感的语音提示，兼具审视与嘲讽风格
- 高阶挑战模式：音效反馈频率提高、节奏紧张，增加压力感
- 隐藏关：环境声音不稳定、音高和回响变化，强化未知与探索感

### 3. 音乐循环与交互
- 主旋律随玩家操作变化，动作节奏、机关触发和法则组合影响音效层级
- 影界操作时，声音映射2D平面上的法则状态，形成操作即时反馈
- 组合多个音效层叠，提供操作“爽感”与策略判断的听觉辅助
