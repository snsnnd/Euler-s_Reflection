# 创意工坊（Creative Workshop）

## 一、模式定位
创意工坊是《欧拉的倒影》中玩家规则创造与分享的模块，玩家可将自己理解的法则与场景设计为可供他人挑战的关卡。工坊的核心目标是让玩家从“规则使用者”升级为“规则创造者”。

## 二、核心玩法
1. **场景布置**：摆放墙体、平台、水面、镜面、投影面、路径结构和区域布局
2. **机制编辑**：放置对称门、映射机、周期盘、连通节点、投影装置、曲率区和拓扑结构
3. **法则配置**：调整重力、周期长度、影界切换权限、资源上限、曲率强度和声画反馈规则
4. **引导编辑**：设置欧拉回声提示风格、叙事碎片、残响文本、视觉高光或误导信息
5. **测试与验证**：玩家必须完成自己设计的关卡无伤通关才能发布

## 三、文档化与发布
- 工坊关卡必须带有完整说明文档，标明核心法则、玩法思路、难度与特色元素
- 系统进行合法性验证后允许上传至社区
- 提供分类标签：#图论 #微积分 #非欧几何 #教学向 #丧心病狂

## 四、社区生态
- 通过排行榜和评价机制提升优秀作品可见性
- 通关率低于1%的关卡将获得“黎曼的凝视认证”徽章，置顶展示
- 玩家可收藏、挑战或评论创作内容

## 五、玩法闭环
1. 玩家创作 -> 测试 -> 发布
2. 社区玩家挑战 -> 收集反馈 -> 修正或创作新关卡
3. 工坊内容可纳入挑战模式、专家档案或隐藏关灵感

## 六、爽感与激励机制
- 创作者看到玩家完成自己的关卡获得评分和徽章
- 高质量关卡可进入专家档案，提升知名度与认可度
- 系统提供直观反馈，强化玩家设计与创作的成就感

## 七、与主线/挑战/隐藏关关系
- 工坊与主线：可以让玩家复现已学的法则或故事元素
- 工坊与挑战：可生成高难度实验性题目
- 工坊与隐藏关：可设计受未解猜想启发的实验关卡，并标注灵感来源
