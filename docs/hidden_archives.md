# 隐藏关：未证回廊（Unproven Archives）

## 一、模式定位
未证回廊是《欧拉的倒影》中承载高不确定性内容的隐藏关系统。它不属于普通主线章节，也不属于标准挑战塔，而是世界中被书库长期封存、无法完全归档的法则边界区域。

其设计目标不是让玩家“证明未解问题”，而是让玩家在未解猜想与边界问题启发下进行：
- 观察
- 实验
- 求生
- 搜索反例
- 逼近边界

## 二、世界观定位
未证回廊在世界观中被解释为：
- 高不确定性区域
- 低稳定度法则区
- 书库禁止初级校准者深入接入的异常区

欧拉回声会将这些区域标记为：
“未归档法则区”

因此，隐藏关不是菜单中的彩蛋，而是世界中真实存在、但需要权限逐步开放的区域。

## 三、解锁规则
### 第一阶段
完成主线第五章“无穷观测所”后，玩家首次检测到未证回廊入口，但无法深入。

### 第二阶段
完成主线第七章“黎曼的扭曲花园”后，开放第一批隐藏关。

### 完整开放
通关主线后，未证回廊的全部内容开放。部分更深层档案可附加要求：
- 特定章节收集完成
- 挑战模式达到一定成绩
- 完成指定隐藏关前置实验

## 四、设计原则
### 1. 不要求标准证明
隐藏关不要求玩家得出数学论文式的结论，也不应该把现实未解问题包装成“可被彻底通关的标准题”。

### 2. 强调研究感
玩家需要感受到自己是在接触：
- 规则的边界
- 世界尚未彻底解释的部分
- 连书库都不愿轻易定义的区域

### 3. 允许阶段完成
隐藏关可以采用多种完成条件：
- 生存一定时间
- 观察若干规律样本
- 找到一定质量的近似构造
- 将系统逼近某个极值阈值
- 未找到反例但完成当前实验阶段

### 4. 强化异常反馈
系统界面、欧拉回声语气、环境渲染、音频反馈都应明显异于普通主线和挑战模式，以形成“禁区感”。

## 五、隐藏关内容分类
### 1. 猜想体验关
用于让玩家感受“为什么某条规律看起来总是成立”。

体验重点：
- 模式反复出现
- 规则简单但结果顽固
- 越实验越觉得它像是真的

### 2. 反例搜索关
玩家主动尝试击穿系统。

体验重点：
- 构造极端情况
- 尝试推翻当前规则
- 观察系统如何不断撑住

### 3. 边界构造关
玩家不去证明，也不去纯生存，而是寻找最接近失效的危险边界。

体验重点：
- 极值构造
- 稳定性压缩
- 接近崩溃但尚未崩溃

## 六、推荐原型关卡
### 1. 冰雹档案（Collatz 灵感）
灵感来源：考拉兹猜想 / 冰雹猜想

玩法思路：
- 玩家输入一个初始数值
- 奇偶规则驱动空间结构不断抛升或坠落
- 玩家必须在序列演化过程中借助平台、节点或轨道求生
- 目标不是“证明猜想”，而是在规则生成的混沌中活下来或达到目标区域

可延展内容：
- 搜索峰值最高的初始数
- 构造尽可能长时间未进入循环的样本
- 观察序列轨迹在影界中的显影图像

### 2. 可证与可求之间（P/NP 气质灵感）
灵感来源：验证与搜索之间的复杂度差异

玩法思路：
- 玩家面对一个大型网络迷宫或全覆盖路径问题
- 系统不给最优解，只给“及格阈值”
- 玩家只需在资源或时间限制下给出一个足够好的合法解
- 本质体验是：验证快于搜索，满意解重于完美解

### 3. 黎曼的凝视（质数分布/频谱灵感）
灵感来源：质数分布背后的深层秩序与频谱气质

玩法思路：
- 关卡空间被表示为看似杂乱但受更深层波动控制的区域
- 玩家并不直接“预测质数”，而是通过频谱显影、波峰波谷和结构密度判断安全落点或路径
- 目标是穿越不稳定区域或找到规律最强的通路带

### 4. 反例猎场
灵感来源：一般化的反例搜索与边界实验

玩法思路：
- 系统给出一个看似稳定的规则
- 玩家通过有限工具不断构造极端案例
- 若无法找到反例，则进入下一实验阶段
- 若触发异常样本，则系统会给出特殊崩坏反馈

## 七、玩法循环
1. 发现或解锁隐藏关入口
2. 欧拉回声提示当前区域的不稳定性质
3. 玩家进入实验空间
4. 观察法则样本或系统演化
5. 在实界/影界中执行构造、干预或求生操作
6. 获得阶段反馈
7. 完成当前研究目标或触发异常结果

## 八、异常反馈与彩蛋设计
隐藏关应强化“不属于常规书库内容”的感觉，可使用：
- 读数失真
- UI 波动
- 日志破碎
- 伪系统崩溃
- 欧拉回声语气变化
- 环境音乐不稳定收敛

彩蛋示例：
若玩家在极低概率下触发某类异常反例条件，系统可以短暂进入伪崩坏状态，并弹出风格化警告信息，但必须明确其为游戏世界内反馈，不暗示现实世界已被真正证明或推翻。

## 九、与主线和挑战的关系
### 与主线的关系
- 主线负责理解规律
- 隐藏关负责触碰规律边界

### 与挑战的关系
- 挑战模式强调熟练应用和效率
- 隐藏关强调高不确定性、研究感和未知边界

### 与工坊的关系
创意工坊可开放“研究型”标签，让创作者设计受未解猜想启发的关卡，但需明确标记为“灵感来源”，避免误导为现实问题已被解决。

## 十、情绪目标
隐藏关应让玩家获得以下感受：
- 这里不是普通关卡
- 我不是在刷题，而是在接触禁区
- 我可能没有得到最终答案，但我看见了边界
- 世界上有些规律，连世界自己都还没有说完
