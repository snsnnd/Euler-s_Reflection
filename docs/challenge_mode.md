# 挑战模式：悖论深渊（Paradox Abyss）

## 一、模式定位
悖论深渊是《欧拉的倒影》的高重玩、高压试炼模式，在完整通关主线后解锁。

主线模式负责让玩家理解法则，挑战模式负责让玩家真正掌控法则。它不是教学模式，也不是剧情章节，而是将主线中已经掌握的规律重新组合、放大、限制并施加压力，以形成真正具有重复游玩价值的规则试炼。

## 二、开启条件
- 完整通关主线模式后开启
- 开启后可从主菜单直接进入
- 部分高阶内容需达到一定挑战层数或评级后解锁

## 三、核心玩法目标
挑战模式强调以下四点：
1. **熟练应用**：要求玩家快速识别并操作规律，而非第一次理解规律
2. **多规律组合**：将对称、映射、周期、连通、投影、曲率等规则交叉叠加
3. **限制条件**：通过步数、时间、视角切换次数、资源数量等形成压力
4. **爽感反馈**：通过连锁修复、节奏同步、Build 成型和局部翻盘给玩家正反馈

## 四、整体玩法循环
1. 进入挑战局或试炼塔
2. 读取本局法则模板与限制条件
3. 在实界/影界中快速识别结构
4. 利用有限资源完成局部与整体修复
5. 获取评分、奖励与公理碎片
6. 进入下一层或结算本局成绩

## 五、内容结构
### 1. 试炼塔
以单一规律为核心、逐层增强难度的固定内容。适合练习基础能力。

示例：
- 对称试炼塔
- 映射试炼塔
- 周期试炼塔
- 连通试炼塔
- 投影试炼塔

### 2. 深渊局
半程序化生成的长局内容，是挑战模式的核心玩法。

每局由以下因素组合而成：
- 核心规律模板
- 房间布局变体
- 参数扰动
- 限制条件
- 正面增益 / 负面词缀

### 3. 每日悖论
官方每天刷新统一种子图，所有玩家面对相同挑战。

评分维度包括：
- 最短步数
- 最快时间
- 最少影界切换次数
- 无失误通关

### 4. 专家档案
由官方或精选创作者提供的高质量手工题库。强调精巧设计、高难度和传播性。

### 5. 深渊赛季
赛季性加入全局扰动规则，例如：
- 所有周期长度 +1
- 影界使用次数减半
- 某类节点延迟响应
- 固定开启曲率干扰

## 六、挑战题型设计
### 1. 单规律纯化题
只围绕一类法则展开，检验玩家是否真正掌握本质。

### 2. 双规律叠加题
典型组合：
- 对称 + 映射
- 周期 + 连通
- 投影 + 路径优化
- 曲率 + 连通

### 3. 资源限制题
- 限步数
- 限时间
- 限影界切换次数
- 限移动对象数量
- 限激活节点数量

### 4. 近似最优题
不要求唯一最优解，但要求结果达到系统阈值内的“满意解”。

### 5. 动态扰动题
规则在解题过程中会持续变化，例如：
- 镜像轴旋转
- 周期结构持续转动
- 部分节点临时失效
- 曲率区域周期性扩张

### 6. 深渊研究题
挑战模式与隐藏关之间的过渡题型，带有更强的边界测试与极端参数色彩。

## 七、难度系统
挑战模式沿用全游戏统一命名：
- 大天才
- 小天才
- 正常人
- 小傻瓜
- 天才
- 黎曼的凝视

在挑战模式中，这套难度对应的是**题目强度**，而不是主线中的“引导层级”。

具体变化包括：
- 变量规模
- 多规律叠加数量
- 时间与步数压力
- 资源限制程度
- 误导元素数量
- 辅助视图开放程度

## 八、Roguelite 机制：公理碎片
玩家在挑战局推进过程中可获得“公理碎片”，用于构成局内 Build。

示例碎片：
- **镜面宽恕**：允许一次不完美对称仍被判定成立
- **延迟回声**：周期机关晚一拍结算
- **局部平直化**：小范围曲率区域暂时恢复欧式空间
- **影界余温**：退出影界后显影信息保留 3 秒
- **反例缓刑**：一次致命错误不会立刻失败
- **节点保边**：一次连通中自动保留一条关键边

## 九、爽感设计
挑战模式必须提供足够的正反馈，降低普通玩家面对高门槛时的流失风险。

核心爽感来源：
1. **连锁破解爽**：一步操作引发整片区域同步恢复
2. **掌控规则爽**：熟练玩家可以快速预判并高效解题
3. **节奏同步爽**：周期类和连通类挑战中形成明显节奏感
4. **Build 成型爽**：公理碎片组合使玩家产生本局“成型”体验
5. **逆转翻盘爽**：在高压局中通过关键一步逆转局势

## 十、评分与结算
挑战模式的评价维度包括：
- 通关时间
- 步数
- 影界切换次数
- 错误次数
- 是否使用辅助
- 是否达到专家阈值
- 连锁恢复次数

系统结算文案应保持统一人格风格，例如：
- “你通了。我们不高兴，但承认这件事发生过。”
- “这不是优雅，这是幸存。”
- “你离专家阈值只差两步。可惜通常最贵的就是这两步。”

## 十一、与主线模式的关系
主线模式让玩家学会“看懂规律”，挑战模式要求玩家“掌控规律”。

主线负责建立：
- 世界观理解
- 规律直觉
- 法则语义

挑战负责检验：
- 速度
- 稳定性
- 组合能力
- 极限处理能力

## 十二、与工坊和隐藏关的关系
- 工坊中的高质量作品可被纳入“专家档案”
- 隐藏关中的边界实验可反向启发高阶深渊题型
- 挑战模式是连接主线理解与隐藏关探索的中间层
