# 玩法系统

## 核心玩法
玩家在3D实界中探索、观察环境和机关，在2D影界中显影并重排法则关系，再返回3D验证结果，形成“观察—操作—验证—修复”的闭环。

## 核心循环
1. **观察现象**：识别异常结构和机关
2. **切入影界**：显影法则和关系
3. **重排法则**：操作节点和机关，调整结构
4. **验证结果**：观察修复效果，推动剧情

## 核心玩家行为
- 移动、观察、切换视角
- 操作、推演、重构、验证
- 组合多种法则完成任务
- 创造并编辑自定义谜题（创意工坊）

## 模式分类玩法
- **主线模式**：章节化叙事与启发式解谜
- **挑战模式**：高压规则试炼与连锁操作
- **隐藏关**：未解猜想启发，高不确定性实验
- **创意工坊**：场景与法则设计，社区分享
