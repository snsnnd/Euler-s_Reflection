# 玩法系统（Gameplay Systems）

本作的玩法系统目标如下：

1. 将数学规律转化为可视化、可交互、可验证的世界法则。
2. 通过 3D 实界与 2D 影界的双层结构，建立区别于传统解谜游戏的核心交互。
3. 在主线中实现“启发式理解”，在挑战中实现“高压应用”，在隐藏关中实现“边界实验”，在工坊中实现“规则创造”。
4. 让玩家在“观察—理解—重排—验证”的过程中获得稳定的认知成长与情绪回报。

------

## 核心玩法定义

《欧拉的倒影》的核心玩法定义如下：

**玩家在 3D 实界中观察空间异常与物理结果，在 2D 影界中读取、显影并重排法则关系，再返回 3D 实界验证重排结果，最终使局部或整体世界重新满足成立条件。**

该定义包含四个核心动作层：

### 观察

玩家在实界中识别异常现象，包括但不限于：

- 结构失衡
- 镜像失配
- 周期错拍
- 节点断连
- 路径失真
- 光路偏移
- 曲率异常

### 显影

玩家进入影界，以二维抽象形式查看当前区域的法则结构，包括：

- 对称轴
- 节点与边
- 输入输出关系
- 周期轮转
- 投影关系
- 结构连接方式
- 扭曲区域边界

### 重排

玩家在实界与影界中通过操作改变世界关系，包括：

- 移动物体
- 调整节点
- 激活/关闭机关
- 变换输入输出
- 旋转/翻折结构
- 重组连接关系
- 改变局部法则状态

### 验证

玩家回到实界观察结果反馈。验证形式包括：

- 门体开启
- 通路恢复
- 水道导通
- 结构复位
- 光束闭环
- 周期同步
- 大范围连锁修复

------

## 核心玩家行为（Core Player Verbs）

本作的基础玩家行为分为以下九类：

### 移动

在三维空间中探索遗迹、观察结构、接近交互点。

### 观察

通过视角变化、环境提示、动态异常与显影读数寻找问题源。

### 切换

在实界与影界之间切换，以获得不同层级的空间信息与法则可见性。

### 操作

对机关、节点、镜面、平台、输入装置、周期结构等进行直接交互。

### 推演

根据已观察到的规律，形成局部或整体解法推断。

### 重构

修改结构关系，使法则重新成立。

### 验证

以实际结果测试重构是否有效。

### 组合

在后期或挑战玩法中，将多种法则组合运用。

### 创造

在创意工坊中构建场景、规则与引导逻辑。

------

## 核心玩法循环（Core Gameplay Loop）

本作的标准玩法闭环如下：

**进入区域**
→ **识别异常**
→ **切入影界显影**
→ **分析法则结构**
→ **进行实界/影界操作**
→ **观察反馈结果**
→ **局部修复完成**
→ **获得叙事推进、系统反馈或新权限**
→ **进入下一问题层**

### 微循环

单个谜题或机关的基本循环：

- 发现问题
- 获取信息
- 局部尝试
- 得到反馈
- 修正思路
- 完成修复

### 中循环

单个房间或子区域的循环：

- 解决若干局部问题
- 激活一组结构
- 打开区域通路
- 获得叙事残片或权限

### 大循环

单章内容的循环：

- 学习一种法则
- 经历该法则的稳定状态、异常状态、变形状态
- 完成章节核心重构
- 理解该章节背后的世界观含义

------

## 双视角系统（World Layer System）

双视角系统是本作最核心的差异化玩法系统。

### 实界（3D Reality Layer）

实界是玩家默认活动层，负责承载：

- 探索
- 空间距离感
- 实体机关
- 路径判断
- 环境叙事
- 物理反馈

实界强调的是**现象与结果**。

### 影界（2D Law Layer）

影界是法则显影层，负责承载：

- 结构抽象
- 节点简化
- 对称与映射可视化
- 周期与路径关系展示
- 连接方式重排
- 局部法则重写

影界强调的是**关系与条件**。

### 双视角关系

两层之间的关系不是“一个真实，一个虚假”，而是：

- 实界展示世界的可感知结果
- 影界展示世界的成立条件

玩家必须在两层之间来回工作，才能完成有效解谜。

### 高阶双视角玩法

随着游戏推进，双视角系统可进一步扩展为：

- 将 3D 实体投影到 2D 平面
- 在 2D 中改变连接后影响 3D 结构
- 在影界中翻折拓扑连接，回到实界后重构空间
- 在特殊区域中实现两层局部重叠

------

# 模式关系与成长闭环

四大模式并非平行独立，而是构成一条完整成长链：

### 主线模式

负责让玩家**看懂规律**。

### 挑战模式

负责让玩家**掌控规律**。

### 隐藏关

负责让玩家**触碰规律的边界**。

### 创意工坊

负责让玩家**创造规律体验**。

因此，本作的长期成长不是数值成长，而是认知成长：
**理解 → 应用 → 探索边界 → 创造表达**

------

## 结论

《欧拉的倒影》的玩法系统并非基于传统谜题堆叠，而是围绕“实界/影界双视角 + 法则重构”展开的统一结构。
玩家在整个产品生命周期中的核心体验是：从观察异常，到理解规则，到掌控规则，再到创造规则。

本作四大内容模块的玩法职责明确如下：

- **主线模式**：启发式理解与叙事推进
- **挑战模式**：高压应用与重玩竞争
- **隐藏关**：边界实验与前沿触碰
- **创意工坊**：规则设计与社区表达

这四者共同构成《欧拉的倒影》的完整玩法骨架。
